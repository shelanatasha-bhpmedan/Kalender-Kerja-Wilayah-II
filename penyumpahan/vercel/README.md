# Link pendek aplikasi (Vercel)
Folder ini hanya mengalihkan `https://<nama>.vercel.app` ke Web App Apps Script.
Ganti link di **vercel.json** dan **index.html** bila URL deployment berubah.
Di Vercel: *Add New → Project → Import* repo ini, isi **Root Directory = `penyumpahan/vercel`**, nama proyek `dokumensumpah`, lalu Deploy.
